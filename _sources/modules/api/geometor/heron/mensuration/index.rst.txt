geometor.heron.mensuration
==========================

.. py:module:: geometor.heron.mensuration

.. autoapi-nested-parse::

   Exact symbolic mensuration formulas and rational approximations from Hero's Metrica.

   Implements Hero of Alexandria's plane and solid mensuration algorithms in 100% exact
   SymPy algebra alongside Norman J. Wildberger's Rational Trigonometry quadrea identity:

   - **Heron's Formula & Archimedes' Quadrea** (*Metrica* I.8; *Wildberger* W.07).
   - **Hero's Iterative Square-Root Extraction** (*Metrica* I.8: :math:`\sqrt{720}`).
   - **Pentagon Golden Section Lemma** (*Metrica* I.18 Lemma over :math:`\mathbb{Q}(\phi)`).
   - **Regular Polygon Area Ratios** (*Metrica* I.17–I.25, :math:`n = 3 \dots 12`).
   - **Dionysodorus's Torus Theorem** (*Metrica* II.13: :math:`V = 2\pi^2 R r^2`).
   - **Truncated Pyramid/Cone Mean-Plus-Third-Difference Identity** (*Metrica* II.6–10).
   - **Exact Volumes of the Five Platonic Solids** (*Metrica* II.16–19).

.. py:function:: pentagon_golden_lemma() -> dict[str, sympy.Expr]

   Verify Hero's *Metrica* I.18 Golden Section Lemma in :math:`\mathbb{Q}(\phi)`.

   In right triangle :math:`AB\Gamma` with :math:`\angle\Gamma = 90^\circ` and
   :math:`\angle A = 36^\circ = \frac{2}{5}\cdot 90^\circ`, doubling :math:`A\Gamma`
   to :math:`A\Delta = 2\cdot A\Gamma` yields :math:`\angle AB\Delta = 108^\circ`,
   so :math:`A\Delta` is cut in extreme and mean ratio with greater segment :math:`AB`:
   :math:`AB = A\Delta / \phi = (2/\phi)\cdot A\Gamma = (\sqrt{5} - 1) A\Gamma`,
   hence :math:`(AB + A\Gamma)^2 = 5 \cdot A\Gamma^2`.

   :returns: Dictionary of exact symbolic invariants and Hero's :math:`81 : 16` rational proxy.

.. py:function:: dionysodorus_torus_volume(major_radius: int | sympy.Expr, minor_radius: int | sympy.Expr, *, pi_approx: sympy.Rational | None = None) -> sympy.Expr

   Compute the volume :math:`V = 2\pi^2 R r^2` of a torus (*σπεῖρα*, *Metrica* II.13).

   On Hero's *Metrica* II.13 dimensions (:math:`R = 14, r = 6`) with Archimedean
   :math:`\pi \approx 22/7`, returns the exact fraction :math:`69696/7 = 9956\frac{4}{7}`.

   :param major_radius: Distance :math:`R` from torus center to generating circle center.
   :param minor_radius: Radius :math:`r` of the generating meridian circle.
   :param pi_approx: Optional rational proxy for :math:`\pi` (e.g., ``sp.Rational(22, 7)``).

   :returns: Exact SymPy expression (or :class:`sympy.Rational` if ``pi_approx`` is rational).


.. py:function:: frustum_volume(b1: int | sympy.Expr, b2: int | sympy.Expr, height: int | sympy.Expr) -> sympy.Expr

   Compute square pyramidal frustum volume via Hero's *Metrica* II.6/II.9 decomposition.

   Evaluates :math:`V = h \left[ ((b_1 + b_2)/2)^2 + \frac{1}{3}((b_1 - b_2)/2)^2 \right]`.

   :param b1: Lower square base edge :math:`b_1`.
   :param b2: Upper parallel square edge :math:`b_2`.
   :param height: Perpendicular altitude :math:`h`.

   :returns: Exact simplified SymPy expression equal to :math:`\frac{h}{3}(b_1^2 + b_1 b_2 + b_2^2)`.
