geometor.heron.render
=====================

.. py:module:: geometor.heron.render

.. autoapi-nested-parse::

   Publication-grade interactive ``.euclid-graphic`` SVG renderer for ``geometor.heron``.

   Serializes exact :class:`~geometor.model.Model` constructions into crisp pixel-space
   SVGs conforming simultaneously to:

   1. Standalone GitHub / browser dark- and light-mode viewing via CSS custom properties, and
   2. ``photon-platform/publish`` interactive figures (``svg.euclid-graphic``, ``<defs>``
      midpoint equality markers ``#geom-tick-1..3``, 3-vertex ``<path>`` segments and lines,
      ``#elements``, ``#graphics``, ``#highlights``, ``#points``, ``#labels``, ``data-ref``,
      and ``data-aliases`` consumed by ``geometor_interactive.js``).

.. py:function:: render_svg_string(model: geometor.model.Model, *, graphic_id: str = 'g1', title: str = 'Hero Geometric Construction', width: int = 700, height: int = 480, margin: float = 42.0, bbox: tuple[float, float, float, float] | None = None, include_guides: bool = False, show_labels: bool = True, label_overrides: dict[str, tuple[str, str]] | None = None) -> str

   Render a :class:`~geometor.model.Model` into a complete ``.euclid-graphic`` SVG string.

   :param model: Populated :class:`~geometor.model.Model`.
   :param graphic_id: ``data-graphic-id`` identifier for ``geometor_interactive.js``.
   :param title: Accessible SVG title string.
   :param width: Pixel width of the SVG ``viewBox``.
   :param height: Pixel height of the SVG ``viewBox``.
   :param margin: Outer pixel margin around the framed geometry.
   :param bbox: Optional explicit math viewport ``(xmin, xmax, ymin, ymax)``.
   :param include_guides: If ``True``, also render elements marked ``guide=True``.
   :param show_labels: Master toggle for point text labels.
   :param label_overrides: Optional mapping ``pt_id -> (base, subscript)``.

   :returns: UTF-8 XML/SVG string.

   :returns: Resolved :class:`~pathlib.Path` of the written SVG file.
