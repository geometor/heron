==============
GEOMETOR heron
==============

Scholarly Multi-Track Book Codex and exact symbolic ``SymPy`` + ``geometor.model``
constructions for **Hero (Heron) of Alexandria** (*fl.* c. 60 CE) — centered on
*Metrica* (*Μετρικά*, Books I–III, ed. Hermann Schöne, Leipzig: B. G. Teubner, 1903)
with selections from *Definitiones* (ed. Heiberg 1912), *Catoptrica* (ed. Schmidt 1900),
and *Dioptra* (ed. Schöne 1903).
