geometor.heron.render¶

Publication-grade interactive .euclid-graphic SVG renderer for geometor.heron.

Serializes exact Model constructions into crisp pixel-space SVGs conforming simultaneously to:

  1. Standalone GitHub / browser dark- and light-mode viewing via CSS custom properties, and

  2. photon-platform/publish interactive figures (svg.euclid-graphic, <defs> midpoint equality markers #geom-tick-1..3, 3-vertex <path> segments and lines, #elements, #graphics, #highlights, #points, #labels, data-ref, and data-aliases consumed by geometor_interactive.js).
